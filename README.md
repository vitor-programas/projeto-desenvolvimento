# BookStore - Projeto Desenvolvimento

Backend: Node.js + Express + MVC (porta 3000)
Frontend: Next.js (porta 3001)

## Como rodar

Precisa ter o Node.js instalado.

**Jeito fácil (Windows):** dê dois cliques em `iniciar.bat` e depois abra http://localhost:3001

**Jeito manual (2 terminais):**

Terminal 1:
    cd backend
    npm install
    node server.js

Terminal 2:
    cd frontend
    npm install
    npm run dev
